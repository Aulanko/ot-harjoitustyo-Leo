
**Starting the application**

*(Make sure you have python and poetry installed)*

1. copy the project
2. go to harjoitustyo
3. poetry install
4. poetry run invoke start


*(if for some reason there would be missing dependencies, you can just look up what module/dependecy is missing and do: poetry add (missing dependency/module))*







High -> The highest price that the stock reached during the time period

Low -> The lowest price for the stock during the time period

Close -> The stock price at the end of that time period

The stock data is from stock markets that operate -5 hours from the UTC time.
*(aka -5 hours from  Greenwich, England)*
